# Changelog

All notable changes to this package are documented here.

## [1.0.0] - 2026-08-10

### Added

* Initial Camera Shake package.
* Centralized camera shake management.
* Cinemachine integration.
* Configurable camera shake settings.
* Camera shake presets.
* Event-based shake triggering.
* Plug-and-play `CameraShakeManager` prefab.
* Example scene provided as a package sample.
* Singleton package dependency.
